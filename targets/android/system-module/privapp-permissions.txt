# The privileged permissions the PowOS app may hold as a system app - its privapp-permissions allowlist, reviewed:
# each is a power the app gets. build-module.sh fails when the APK requests a privileged permission not listed here
# (the phone enforces the list: one missing and Android won't boot). A system UI slot adds its own here.

# Settings in the secure table (the launcher's own settings: default home, gestures, theming the system).
android.permission.WRITE_SECURE_SETTINGS

# The recents provider (the recents slot: switcher and shade). Its other permissions (STATUS_BAR_SERVICE,
# READ_FRAME_BUFFER, REMOVE_TASKS, INTERNAL_SYSTEM_WINDOW) are recents-only and granted by the role; these two are
# also privileged, so the allowlist is checked for them first. STATUS_BAR: SystemUI's shade switched off while
# PowOS's replaces it (StatusBarManager.disable). START_TASKS_FROM_RECENTS: the switcher brings a task back.
android.permission.STATUS_BAR
android.permission.START_TASKS_FROM_RECENTS
